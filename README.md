# CONTACTS BOOK
Program to saves contact's name and their phone number using BST to search through contacts quickly and map to store contact's phone number.

List of all commands:

```
ADD: Input a new contact if not exist yet.
DELETE: Delete an existing contact with given name.
UPDATE: Update the phone number of specified contact.
GET: Print the contact's name with the phone number.
SEARCH: Print a list of contact's name with the specified keyword.
EXIT: Quit the program.
HELP: List all commands.
HISTORY: Prints 10 last logs made.
```
